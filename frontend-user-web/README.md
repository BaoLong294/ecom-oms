# frontend-user-web

The customer storefront of [Ecommerce – OMS](../README.md), built with React 19 and Vite.

**Live demo:** https://ecom-oms-user-web.vercel.app

```bash
npm install
npm run dev     # start the dev server
npm test        # run the tests
npm run lint    # lint
npm run format  # format
npm run build   # production build
```

See the [main README](../README.md) for features and project details.
